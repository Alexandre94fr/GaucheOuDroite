Ce bloc-note contient les technologies utilisées (ou qui ont prévu d'être utilisées) pour produire ce projet / application.

===========================================================================================================================

Technologies utilisées :
------------------------

FRONT :
- Unity
- C#

BACKEND :
- ASP.NET Core Web API

BDD :
- SQLite

ORM (Mapping objet-relationnel, l'API entre le FRONT et le BACKEND) :
- Entity Framework Core

AUTH :
- JWT (JSON Web Token)

VERSIONNING :
- GitHub (GitHub Desktop)

DEPLOIEMENT :
- En localhost (les données seront sauvegardées de manière persistantes via SQLite, via le fichier DataBase.sqlite)

DOCKER (OPTIONNEL, à faire quand le projet sera complètement fonctionnel, s'il reste encore du temps, et si c'est utile) :
- Dockerfile
- Docker Compose
